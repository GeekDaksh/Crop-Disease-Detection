# 🌾 Crop Disease Detection (FARM-AID)

FARM-AID is an AI-powered crop disease detection system designed to support farmers in **Maharashtra and Gujarat** by enabling **early and accurate identification of crop diseases**. The system uses deep learning models to analyze crop images and provide real-time disease diagnosis for major crops such as wheat, rice, maize, sugarcane, potato, and cotton.

---

## 📌 Project Overview

Crop diseases significantly impact agricultural productivity and farmer livelihoods. FARM-AID addresses this challenge by leveraging computer vision and deep learning to deliver a scalable, field-ready disease detection solution that helps farmers take timely and informed action.

---

## 🌱 Crops Covered

- Wheat  
- Rice  
- Maize  
- Sugarcane  
- Potato  
- Cotton  

Each crop includes both **healthy** and **diseased** classes.

---

## 🧠 Models & Techniques

### Deep Learning Models
- Custom Convolutional Neural Network (CNN) optimized for efficiency and accuracy  
- ResNet50 (fine-tuned)  
- MobileNetV2 (fine-tuned)  
- DenseNet121 (fine-tuned)  
- EfficientNetB0 (fine-tuned)  

### Training Enhancements
- Advanced data augmentation to handle class imbalance  
- Transfer learning for improved convergence and generalization  
- Image normalization and resizing
